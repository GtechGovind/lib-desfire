# Support

Read the [README](README.md), [build guide](docs/building.md) and
[HTTP API reference](docs/http-api.md) first.

- **Questions and reader integration:** use [GitHub Discussions](https://github.com/GtechGovind/lib-desfire/discussions).
- **Reproducible defects:** open a [bug report](https://github.com/GtechGovind/lib-desfire/issues/new?template=bug_report.yml).
- **Improvements:** open a [feature request](https://github.com/GtechGovind/lib-desfire/issues/new?template=feature_request.yml).
- **Vulnerabilities:** follow [SECURITY.md](SECURITY.md) and use private reporting.
- **Financial support:** visit [GitHub Sponsors](https://github.com/sponsors/GtechGovind).

Include the version/commit, platform, compiler and relevant dependency versions.
Use synthetic reproductions, remove secrets and distinguish offline checks from
physical hardware observations. Community support is provided as time permits;
there is no promised response time or commercial support agreement.
